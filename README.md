# Cabinet of Liminal Earths

*A Media-Archaeological Inquiry into Unnameable Landscapes*: Panagiotis Kalantzis.

A web visit of the Pantheon staged as a Wunderkammer: six layers, twenty artifacts. It was made for the
Media Archaeology course (MARes Hybrid Arts, Ionian University) and belongs to the thesis project
*The Negative Atlas* / GeoLogo-Graphia.

**Visit:** https://panagkalan.github.io/pantheon-cabinet/

## Technical
A static site with no build step: three.js r181, three-mesh-bvh and the Draco decoder are bundled in `vendor/`.
To run it locally, serve this folder over HTTP (for example `python -m http.server`) and open `index.html`.
